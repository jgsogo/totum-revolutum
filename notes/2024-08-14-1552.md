Update NPM dependencies in a Bazel monorepo
===========================================

We use a workspace approach for the Javascript dependencies too. The files
that are involved are:

 * `pnpm-workspace.yaml`: lists all the packages in the monorepo
 * `pnpm-lock.yaml`: the unique lockfile for the repository
 * `<package>/package.json`: lists the dependencies for one package

To modify/add dependencies follow the next steps:

 1. Modify the corresponding `package.json` file
 2. Now we need to update the lockfile. We are going to use the `pnpm` version we have
    declared for the whole monorepo:

    > Note.- Use absolute path to the package directory

    ```bash
    bazel run -- @pnpm --dir $(pwd)/<package> install
    ```
