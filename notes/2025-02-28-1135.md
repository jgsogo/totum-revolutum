Containers, deployment and testing
==================================

When did we loose the focus and started to think about containers for deployments?
Is there any scenario where they are better for deployments? Of course, infrastructure
providers find it very convenient, it's great for isolation (filesystem, network, resources,...);
but it's so resource intensive that they are not useful at all for in-house (or local)
deployments.

## Deployments

Let's use as much as possible native applications running in the host OS. Use shared
resources like databases, supervisor, nginx,...

## Testing

Containers are great for testing, though. They are great to create temporal and isolated
environments (database, networks,...) to test or try an application under development.
